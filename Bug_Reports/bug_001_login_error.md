# Баг-репорт: Ошибка 500 при вводе спецсимволов в поле Email

**ID:** BUG-001
**Проект:** Сайт Synergy Academy
**Серьезность (Severity):** Major
**Приоритет (Priority):** High
**Окружение:** Windows 10, Google Chrome (версия 120.0), разрешение экрана 1920x1080.

**Шаги воспроизведения:**
1. Перейти на страницу авторизации (https://new.synergyacademy.com/login).
2. В поле "Email" ввести строку с спецсимволами: `test<>!@domain.com`.
3. В поле "Пароль" ввести любой валидный пароль.
4. Нажать кнопку "Войти".

**Фактический результат:**
Сервер возвращает ошибку "500 Internal Server Error". Страница становится белой, пользователь не может продолжить работу.

**Ожидаемый результат:**
Система должна выполнить валидацию поля на стороне клиента и вывести сообщение: "Введите корректный адрес электронной почты". Ошибка 500 не должна возникать.сохр
